# Dotfiles

Arch Linux + Hyprland setup managed with GNU Stow. The shell is zsh (its own
`zsh` package); theming is handled by
[Noctalia](https://github.com/noctalia-dev/noctalia).

## Prerequisites

```bash
sudo pacman -S git stow noctalia hyprland kitty neovim yazi btop fastfetch \
  mpd rmpc hyprlock udiskie gvfs polkit-gnome zoxide eza fzf fd bat cliphist \
  starship zsh ttf-nerd-fonts-symbols
```

- **Zsh**: no framework — the config is the `zsh` stow package (`ZDOTDIR=~/.config/zsh`,
  set in `/etc/zsh/zshenv`); the prompt is [Starship](https://starship.rs).
  `plugins.zsh` git-clones `zsh-vi-mode`, `zsh-autosuggestions`,
  `zsh-history-substring-search`, and `fast-syntax-highlighting` into
  `~/.config/zsh/plugins/` on first launch (gitignored; refresh with `zplugin-update`).
- **Hyprland plugins**: installed via `hyprpm` (see `hypr/.config/hypr/modules/plugins.lua`).
- **Font**: `Maple Mono NF Propo` (referenced by waybar/kitty).
- **Leaf**: `leaf-markdown-viewer` (AUR) — markdown viewer, themed via Noctalia
  (see Theming).

## Install

```bash
git clone <repo> ~/dotfiles
cd ~/dotfiles
stow btop fastfetch hypr kitty leaf mpd noctalia nvim rmpc swaync wal walker waybar yazi zen zsh
```

`stow` symlinks each package's files into `$HOME` (each top-level dir is a
package: `<pkg>/.config/<app>` -> `~/.config/<app>`).

## Theming

Handled entirely by **Noctalia** — no manual step. On start it renders color
templates for hyprland/kitty/btop/gtk/qt/starship/... and
`hypr/.config/hypr/hyprland.lua` calls `require("noctalia").apply_theme()`.
`hypr/.config/hypr/noctalia.lua` is generated by Noctalia. All rendered outputs
inside packages (`btop/.../noctalia.theme`, `fastfetch/.../noctalia.jsonc`,
`hypr/noctalia.lua`, `kitty/.../noctalia.conf`, `yazi/.../noctalia.yazi/*`) are
generated and gitignored.

Leaf has no built-in Noctalia template, so it uses a **user template** declared
in `noctalia/.config/noctalia/theme.toml` (`theme.templates.user.leaf`). Noctalia
renders `leaf/.config/leaf/noctalia-{dark,light}.toml.template` into
`~/.config/leaf/noctalia.toml`, which `leaf/.config/leaf/config.toml` sets as its
`theme`. The generated `noctalia.toml` is not tracked (see `.gitignore`). Refresh
manually with `noctalia msg templates-apply`.

## Post-install (machine-specific)

- **Monitors**: `hypr/.config/hypr/modules/monitor.lua` (this setup assumes
  `eDP-1` + `HDMI-A-1`).
- **Wallpapers**: create `~/Pictures/Wallpapers`.
- **SSH key**: `~/.ssh/id_ed25519` (added by ssh-agent on start).
- **External scripts (not in this repo)**: `~/.local/bin/{setwal,waybar-reload,
  powermenu,eject-storage.sh}` and `~/scripts/pywal16`.
- **Zen Browser profile**: the `zen` package targets the profile dir
  `~/.config/zen/1gai9kpi.Default (release)/chrome` (name is machine-specific).
  It tracks only the hand-edited `userChrome.css` and `userContent.css`;
  `zen-themes.css` and `locales/` are Zen-generated and left untracked.

## Legacy / unused

`wal`, `waybar`, `swaync`, and `walker` are still stowed but no longer used
(their autostarts are commented out in
`hypr/.config/hypr/modules/autostart.lua`). Kept for reference.
